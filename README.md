> *She doesn't judge. She just watches — and reminds you what's left to do.*

Todo-App is a task manager with Haimiya Mio as an interactive companion character.  
Todos persist via MockAPI. Mio reacts to what you do — idle, focused, or done.

---

## Stack

| | |
|---|---|
| **Framework** | React + Vite |
| **Animation** | Framer Motion |
| **Styling** | SCSS · CSS Variables |
| **Data** | MockAPI |
| **Deployment** | Vercel |

---

## Run locally

```bash
git clone https://github.com/NguyennDangg/Todo-App.git
cd Todo-App
npm install
npm run dev
```
